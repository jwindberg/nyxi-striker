# NYXI CA01 Striker: open-source control

Tools for controlling the NYXI CA01 "Striker" keyboard (backlight, 9x9 screen, settings) without NYXI's Windows-only app.

- `app/`: **the new app** (Tauri + Svelte) for macOS, Windows and Linux: lighting, the 9x9 screen (images and animations included with the app, plus your own, with an editor) and settings.
- `crates/nyxi-core/`: the keyboard protocol in Rust, used by the app, with a small `nyxi` command-line tool.
- `animations/`: the screen images and animations included with the app, generated by `make_animations.py`.
- `PROTOCOL.md`: the complete USB HID protocol. Start here.
- `nyxi_led.py`: read and set the backlight (`python3 nyxi_led.py get`, `python3 nyxi_led.py modes`).
- `nyxi_screen.py`: draw on the 9x9 screen (`python3 nyxi_screen.py heart`).
- `nyxi-driver/`: Rust replacement for NYXI's `iot_driver`, which the official Electron app talks to over gRPC-web on 127.0.0.1:3814.
- `nyxi-app.sh`: runs the official app on macOS or Linux against `nyxi-driver`.
- `setup-official-app.sh`: one-time setup for `nyxi-app.sh`. NYXI's app is their code, so it is not in this repo; this gets it from the private repo `jwindberg/nyxi-official-app` (or from their Windows installer).

## The new app

```
cd app
npm install
npm run tauri dev      # run it
npm run tauri build    # build an installer for this platform
```

Needs Rust and Node.js. On Linux also WebKitGTK (`sudo apt install libwebkit2gtk-4.1-dev build-essential`) and the udev rule below; on Windows the Visual Studio C++ build tools.

### Screen images and animations

Every image and animation the Screen tab lists is a text file in a folder on that computer, in the same format as `animations/*.txt`. The ones included with the app (`animations/`) are a starter set: the app copies them into the folder the first time, and after that they can be edited or deleted like the ones you make.

| Platform | Folder |
| --- | --- |
| Linux | `~/.local/share/com.jwindberg.nyxi/screens/` |
| macOS | `~/Library/Application Support/com.jwindberg.nyxi/screens/` |
| Windows | `%APPDATA%\com.jwindberg.nyxi\screens\` |

The app also shows the exact folder at the bottom of its Screen tab. To use them on another computer, copy the `.txt` files into that computer's folder (for example `scp ~/.local/share/com.jwindberg.nyxi/screens/*.txt othermachine:...`) and reopen the Screen tab. A file added to `animations/` is included with the app for everyone; a newer app copies only screens it hasn't copied before (recorded in the folder's `.included` file), so one you deleted stays deleted. "Restore included screens" at the bottom of the Screen tab puts them all back as they came, replacing your changes to them. ("Built-in" is kept for what the keyboard itself has: the jumping bird, Pac-Man and cat.) Each file is plain text: `; name:`, `; type: image` or `; type: animation`, and `; delay:` lines, then 9×9 frames of `#` and `.`; without a type line, one frame means an image.

## Running the official NYXI app on macOS or Linux

Needs Rust (`rustup`), Node.js/npm and access to the private repo `jwindberg/nyxi-official-app`. On Linux the driver build also needs `sudo apt install libudev-dev`.

```
./setup-official-app.sh    # once per machine; rerun to update the app
./nyxi-app.sh              # builds the driver on first run, then starts it and the app
```

Setup clones the app into `extracted_asar/` and installs it inside the downloaded Electron so it runs as an installed app. Without access to that repo, pass NYXI's Windows installer instead (`./setup-official-app.sh path/to/NYXI_SETUP.exe`, needs 7-Zip: `brew install sevenzip` or `sudo apt install 7zip`); nothing from the `.exe` is executed. On macOS the app starts its own driver from `~/Library/Application Support/NYXI Driver/iot_driver_v160`, so `nyxi-app.sh` puts our driver there before each launch.

On macOS, closing the window leaves the app running; quit it with Cmd+Q to stop the driver too.

### Installable packages

`./package-official-app.sh` (after setup) builds a self-contained package of the app plus our driver for the machine it runs on. These contain NYXI's code: personal use only.

- macOS: `release/NYXI-Driver-mac-<arch>.dmg`. Open it and drag "NYXI Driver" to Applications. On first launch the app copies its driver to `~/Library/Application Support/NYXI Driver/iot_driver_v160`; after installing a newer build, delete that file so the new driver is copied in.
- Linux: `release/NYXI-Driver-linux-<arch>.tar.gz`. Unpack it and run `./install.sh` (installs for your user, adds a menu entry and the `nyxi-app` command; also needs the udev rule below).

Goal: our own cross-platform app (macOS, Windows, Linux) that anyone can build from this repo.

## Linux setup

Let normal users access the keyboard:

```
echo 'SUBSYSTEM=="hidraw", ATTRS{idVendor}=="3151", MODE="0666"' | sudo tee /etc/udev/rules.d/99-nyxi.rules
sudo udevadm control --reload && sudo udevadm trigger
```

The Python tools currently use Linux hidraw ioctls; macOS support comes with the app.
